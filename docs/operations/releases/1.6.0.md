# OneCart Family 1.6.0

## Candidate

- Version/build: **1.6.0 (1)** locally for the app and widget extension, Debug and Release;
  iPhone only. Xcode Cloud assigns the uploaded build number.
- Type: feature release (MINOR) after [1.5.1](1.5.1.md). Task brief:
  [redesign-ios27.md](../../tasks/redesign-ios27.md).
- Scope:
  - Redesign of every screen with iOS 26/27 system idioms. The information architecture is
    unchanged: three tabs (Cart, History, Settings) and the core path of
    [product.md](../../requirements/product.md).
    - Cart: native inset-grouped list with swipe actions, the progress strip as the tab bar
      accessory, a glass add button that morphs into the name-only composer.
    - History: days as a native list; a day opens a read-only detail sectioned by category.
    - Settings: a native `Form` with inset-grouped sections, inline icon and accent pickers,
      members with swipe to remove, share as a secondary action.
    - Welcome: brand hero, feature rows and Sign in with Apple built from system components.
    - Widget: rows, progress line and empty state share the cart's visual vocabulary.
  - Architecture: `AppSession` and its services are `@Observable`; each screen has a
    ViewModel that depends on service protocols; screens no longer reach `AppSession`
    ([architecture.md](../../engineering/architecture.md)).
  - Fix: category refinement no longer undoes a rename made while it runs (REQ-CART-020).
  - Tests: ViewModel, service and hosted-view tests; all 49 requirements are traced to tests.
- Behaviour deltas, all within the existing requirements:
  - Renaming an item uses a system alert instead of inline editing.
  - The members button is always in the cart toolbar.
  - The busy overlay appears only after 400 ms.
  - Destructive actions in Settings are confirmation dialogs.
  - The owner's sharing warning moved to the footer of the Sharing section.
- App Store: 6.9-inch screenshots were refreshed for the redesign
  ([assets/store/README.md](../../../assets/store/README.md)).

## What’s New — English

- A fresh look built for iOS 27: the cart, History, Settings and the widget now use native
  lists, glass controls and the new tab bar.
- Add items faster: the add button turns into the input field in place.
- History opens each day as a read-only list grouped by category.
- Renaming an item no longer gets undone when its category is updated.

## What’s New — Russian

- Новый дизайн для iOS 27: корзина, история, настройки и виджет используют системные списки,
  стеклянные элементы и новую панель вкладок.
- Добавлять товары быстрее: кнопка добавления превращается в поле ввода прямо на месте.
- В истории каждый день открывается списком по категориям, только для просмотра.
- Переименование товара больше не отменяется, когда уточняется его категория.
