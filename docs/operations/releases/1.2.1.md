# OneCart Family 1.2.1

## Summary

- Version **1.2.1**, iPhone only (app and widget extension). Fix-only release: no new
  user-facing features since 1.2.
- Widgets: the family switch handles the iOS 27 `systemExtraLargePortrait` case, and the widget
  has an explicit white light-mode background.
- Delivery: tests run in GitHub Actions and Xcode Cloud archives only from the CI-moved
  `testflight` and `release` branches ([ADR 0003](../../decisions/0003-ci-split.md)).

## What’s New — English

- Home Screen and Lock Screen widgets are ready for iOS 27.
- Stability improvements.

## What’s New — Russian

- Виджеты на экране «Домой» и экране блокировки готовы к iOS 27.
- Улучшена стабильность.
