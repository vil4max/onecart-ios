# OneCart Family 1.5.0

## Summary

- Version **1.5.0**, iPhone only (app and widget extension).
- Same scope and What's New as [1.3.0](1.3.0.md); the 1.5.0 version number follows the
  existing TestFlight 1.4 builds, which TestFlight would otherwise treat as newer.
- The project file is in the JSON project format (`project.xcproj`), and
  `OneCart/ci_scripts/ci_post_clone.sh` sets the build number in that format.
- The App Store Support URL is `https://github.com/vil4max/onecart-ios/issues`, and the Privacy
  Policy URL points to [privacy.md](../../privacy.md) (English and Russian).

## What’s New — English

- A refreshed design for iOS 27, with system glass controls and cleaner Cart and History lists.
- A new app icon, in every theme.
- Widgets now follow your language and adapt to tinted and clear Home Screens.
- Many stability and sync improvements.
- Requires iOS 27.

## What’s New — Russian

- Обновлённый дизайн для iOS 27: системные стеклянные элементы и более чистые списки корзины и
  истории.
- Новая иконка приложения во всех темах.
- Виджеты говорят на вашем языке и подстраиваются под тонированный и прозрачный экран «Домой».
- Множество улучшений стабильности и синхронизации.
- Требуется iOS 27.
