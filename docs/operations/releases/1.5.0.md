# OneCart Family 1.5.0

## Candidate

- Version/build: **1.5.0 (1)** locally for the app and widget extension, Debug and Release; iPhone
  only. Xcode Cloud assigns the uploaded build number.
- Same scope and What's New as [1.3.0](1.3.0.md), which never reached testers.
- Why 1.5.0 and not 1.4.0: App Store Connect already holds TestFlight builds 76–83 of a **1.4**
  version record (August to September 1, 2026). On 2026-09-21 the TestFlight app showed the
  owner 1.4 (82) as the current build and no 1.3.0 update, although 1.3.0 (111, 112) was Ready
  to Submit for the same group. The working assumption is that TestFlight treats the higher
  version as newer; 1.4.0 would compete with the existing 1.4 builds, so 1.5.0 is the next
  MINOR above them (AGENTS.md versioning). The first 1.5.0 round confirms or refutes it.
- App Store: the version record prepared as 1.2.2 has to be named 1.5.0 when this build is
  submitted. Its Support URL changes to `https://github.com/vil4max/onecart-ios/issues` in the
  same record ([release.md](../release.md)).
