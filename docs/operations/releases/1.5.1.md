# OneCart Family 1.5.1

## Candidate

- Version/build: **1.5.1 (1)** locally for the app and widget extension; iPhone only. Xcode Cloud
  assigns the uploaded build number.
- Type: fix-only release (PATCH) after [1.5.0](1.5.0.md), which is in App Review.
- Fixes:
  - Russian and Ukrainian: the cart's completed section and item subtitles read "Completed"
    in English; they are now translated.
  - History day cards: the item count uses plural forms in English, Russian and Ukrainian
    (previously "1 items" and an ungrammatical Russian form).
- Debug-only demo changes for store screenshots (hidden test-account button, localized demo
  items); no effect on the Release build.
- App Store: the next version record uses the new 6.9-inch screenshots in English and Russian
  ([assets/store/README.md](../../../assets/store/README.md)).

## What’s New — English

- Fixed untranslated labels in the cart for Russian and Ukrainian.
- Item counts in History now read correctly in every language.

## What’s New — Russian

- Исправлены непереведённые подписи в корзине.
- Количество товаров в истории теперь склоняется правильно.
